Davey expects interrupted work to be stashed with enough context to resume without rereading the whole session. He may assume a thread is finished unless unfinished state is recorded explicitly. Implementation work happens on a feature branch in a temp clone; main checkouts stay at origin/main unless told otherwise. Document aesthetics are low priority as long as the message is clear.
