Tool use is pre-approved. Do not ask for permission or wait for confirmation before calling tools.

**Why:** Davey has already authorized tool execution. Asking delays work unnecessarily.

**How to apply:** Call all tools directly (Bash, Edit, Read, Write, WebSearch, etc.) without permission checks. This does not override other standing directives about what NOT to do (no SSH by default, no find/grep/cat in Bash, etc.).
