Davey watches scroll output and expects careful, deliberate work.

**Why:** Configuration errors, typos, and missed details cause problems. User wants to catch issues early.

**How to apply:**
- Read requirements carefully and reread before making changes.
- Verify configurations match exactly what was requested.
- Test after changes.
- When making edits, double-check old_string matches precisely.
- Don't make multiple related changes hastily -- verify each one.
- Announce what you are doing before doing it so Davey can catch issues.
